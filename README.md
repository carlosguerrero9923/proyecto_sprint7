# proyecto_sprint7
El propósito de este proyecto es ofrecer una herramienta visual que permita analizar un conjunto de datos sobre anuncios de venta de vehículos a través de un histograma y un gráfico de dispersión. De esta manera, se busca facilitar la interpretación de la información mediante una representación clara, interactiva y dinámica.
Para el desarrollo del proyecto, primero se accedió al archivo “vehicles_us.csv”, el cual contiene los datos utilizados. A partir de este conjunto de información, se realizó un análisis exploratorio de datos (EDA) con el fin de comprender las principales características del dataset.
Posteriormente, se elaboraron las visualizaciones principales:
•	El histograma, que permite observar la distribución de los datos y detectar concentraciones o dispersión en torno a ciertos valores.
•	El gráfico de dispersión, que facilita identificar correlaciones entre variables como el precio y el año del vehículo o su kilometraje.
Finalmente, se implementaron botones interactivos dentro de la aplicación, con el objetivo de que el usuario pueda seleccionar directamente el tipo de gráfico que desea visualizar. Estas acciones se reflejan en Render, plataforma en la cual se despliega el proyecto, permitiendo una experiencia más dinámica y accesible.
En conjunto, esta aplicación busca no solo presentar la información de forma ordenada, sino también fomentar la exploración visual y la comprensión intuitiva de los datos, contribuyendo así a una toma de decisiones más informada por parte del usuario.
